# Biz.Bizadm.MPQ.NET

Pure .NET library for reading and writing Blizzard MPQ archives.

Layout: `src/` (library), `tests/`, `tools/`.

Consumer docs (install, quick start): [src/Biz.Bizadm.MPQ.NET/README.md](src/Biz.Bizadm.MPQ.NET/README.md)

## Build

```bash
dotnet build Biz.Bizadm.MPQ.NET.slnx
```

## Test

```bash
dotnet test tests/Biz.Bizadm.MPQ.NET.Tests
```
