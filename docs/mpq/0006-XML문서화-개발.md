# XML 문서화 개발

## 작업 단위

### 1. csproj

- **대상**: `src/Biz.Bizadm.MPQ.NET/Biz.Bizadm.MPQ.NET.csproj`
- **선행**: 없음
- **코드 초안**:

```xml
<PropertyGroup>
  <GenerateDocumentationFile>true</GenerateDocumentationFile>
</PropertyGroup>
```

- **검증**: 속성 존재 확인 후 단위 2로 진행(전체 빌드는 단위 3에서)

### 2. 공개 API XML 보강

- **대상**: 루트 공개 `.cs` 파일의 `CS1591` 멤버
- **선행**: 단위 1
- **코드 초안** (누락 예):

```csharp
/// <summary>Archive header.</summary>
public MpqHeader Header { get; private set; }

/// <summary>Opens an archive file.</summary>
public static MpqArchive Open(string path, MpqOpenMode mode = MpqOpenMode.Read, MpqOpenOptions? options = null)
```

```csharp
/// <summary>Uncompressed file size in bytes.</summary>
public required long FileSize { get; init; }
```

```csharp
/// <summary>Default options.</summary>
public static MpqOpenOptions Default { get; } = new();
```

실제 문구는 기존 파일의 영어 톤에 맞추고, `dotnet build`의 `CS1591` 목록을 기준으로 빠진 멤버를 모두 채운다.

- **검증**: 단위 3과 함께

### 3. 빌드 검증

- **대상**: 라이브러리 프로젝트
- **선행**: 단위 1·2
- **검증**:

```powershell
dotnet build src/Biz.Bizadm.MPQ.NET/Biz.Bizadm.MPQ.NET.csproj
```
