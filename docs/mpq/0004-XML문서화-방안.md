# XML 문서화 방안

## 문제·목표

- NuGet/IDE IntelliSense용 XML 문서 파일을 빌드 산출물에 포함하려면 `GenerateDocumentationFile`이 필요하다.
- 켜면 공개 멤버의 누락 주석이 `CS1591`로 경고된다. 공개 API에 필요한 XML을 채워 경고 없이 문서 파일을 생성한다.

## 채택 방안

| 항목 | 결정 |
|---|---|
| 범위 | 공개(`public`) API만. `Internal/`, `Compression/`은 보강하지 않음 |
| 경고 | `CS1591`을 `NoWarn`하지 않고 누락 `<summary>`를 모두 기입 |
| 언어 | 기존과 동일하게 영어 |
| 설정 위치 | 라이브러리 [`Biz.Bizadm.MPQ.NET.csproj`](../../src/Biz.Bizadm.MPQ.NET/Biz.Bizadm.MPQ.NET.csproj)만. `Directory.Build.props`·테스트 프로젝트에는 넣지 않음 |

## 비범위

- internal 멤버 문서 완성
- 공개 API 동작·시그니처 변경
- DocFX/외부 사이트 문서 생성
