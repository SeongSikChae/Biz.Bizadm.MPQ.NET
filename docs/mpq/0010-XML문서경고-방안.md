# XML 문서 경고 방안

## 문제·목표

- `GenerateDocumentationFile` 빌드에서 일부 메서드만 `<param>`이 있어 `CS1573`이 난다.
- 같은 빌드의 `CS0419`는 `MpqSignatureStatus`의 `VerifySignature` cref가 오버로드로 모호하다.
- 누락 `<param>`을 채워 두 경고를 없앤다.

## 채택 방안

| 항목 | 결정 |
|---|---|
| 조치 | 누락 `<param>` 채움 (기존 태그 삭제 아님) |
| 범위 | 직전 Release 빌드 CS1573 전부 + CS0419 |
| 언어 | 영어 |

## 비범위

- `NoWarn`으로 숨기기
- 문서 없는 멤버 CS1591 전수 점검
- API·동작 변경
