# XML 문서화 설계

## 구조

```
Biz.Bizadm.MPQ.NET.csproj
  └── GenerateDocumentationFile=true
        └── 빌드 시 Biz.Bizadm.MPQ.NET.xml 산출
              └── CS1591: 공개 멤버에 <summary> 필수
```

## 대상 표면

루트 네임스페이스 `Biz.Bizadm.MPQ.NET`의 공개 타입·멤버:

- `MpqArchive` (partial: 본문, Write, Modify, Signature, Patch)
- `MpqEntry`, `MpqFileStream`
- `MpqOpenOptions`, `MpqArchiveCreateOptions`, `MpqAddFileOptions`
- `MpqHeader`, `MpqHeaderV4`, `MpqUserData`
- `MpqOpenMode`, `MpqFormatVersion`, `MpqFileFlags`, `MpqCompressionType`, `MpqSignatureStatus`

`Stream` override(`CanRead` 등)도 공개이므로 `CS1591` 대상이다.

## 문서 규칙

- 짧은 영어 `<summary>`; 기존 주석 톤 유지
- 필요 시 `<param>`, `<exception>`, `<see cref>`
- `<returns>`는 summary만으로 반환 의미가 불명확할 때만
- 이미 summary가 있는 멤버는 수정하지 않음(누락만 채움)

## 의존성·영향

- 런타임 의존성 없음
- 테스트 프로젝트·공개 API 계약 변경 없음
- NuGet pack 시 XML이 패키지에 포함됨(SDK 기본)

## 검증

`dotnet build` 종료 코드 0, 출력에 `CS1591` 없음, `bin` 아래 `.xml` 존재.
